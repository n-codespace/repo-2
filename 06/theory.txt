================================================================================
ASSIGNMENT 06: BUILD A REAL CI PIPELINE USING JENKINS SCRIPTED PIPELINE
================================================================================

1. AIM / OBJECTIVE:
To create a simple, easy Continuous Integration (CI) pipeline using Jenkins Scripted Pipeline (Groovy DSL) that automatically checks out code, runs automated tests, and executes a JavaScript/Node.js application.

2. WHAT IS A SCRIPTED PIPELINE?
A Scripted Pipeline is written in Groovy syntax and executes inside a `node { ... }` block.
- It gives developers full programming control (conditions, loops, custom logic).
- It is flexible and runs line-by-line.

3. DIFFERENCE: DECLARATIVE VS SCRIPTED PIPELINE:
- Declarative Pipeline: Uses `pipeline { stages { ... } }`. Strict and rigid format.
- Scripted Pipeline: Uses `node { stage('Name') { ... } }`. Flexible, programmatic Groovy code.

4. PIPELINE STAGES EXPLAINED (SUPER SIMPLE):
- Stage 1 (Checkout): Pulls the latest project code from Git.
- Stage 2 (Run Automated Tests): Runs `node --test test_app.js` to ensure functions work properly.
- Stage 3 (Run Application): Runs `node app.js` to execute the application.
- Stage 4 (Pipeline Finished): Prints success confirmation.

5. HOW TO RUN IN JENKINS:
Step 1: Open Jenkins Dashboard (http://localhost:8080).
Step 2: Click "New Item" -> Enter "Simple-Scripted-CI" -> Select "Pipeline" -> Click OK.
Step 3: In the Pipeline Script box, paste the contents of `06/Jenkinsfile`.
Step 4: Click Save -> Click "Build Now".
Step 5: View the Console Output to see all 4 stages pass with SUCCESS!

6. CONCLUSION:
The Jenkins Scripted Pipeline provides a straightforward way to automate testing and running code whenever changes are committed.
