================================================================================
ASSIGNMENT 09: LOGIN TO AZURE PORTAL AND CREATE A WEB APP
================================================================================

1. AIM / OBJECTIVE:
To log into the Microsoft Azure Portal, navigate the Azure App Service ecosystem, create a cloud-hosted Web App on Linux using the Free F1 pricing tier, and verify deployment.

2. WHAT IS AZURE APP SERVICE?
Azure App Service is a Platform-as-a-Service (PaaS) offering provided by Microsoft Azure. It allows developers to build, host, and scale web applications, RESTful APIs, and mobile backends without the overhead of provisioning, patching, or managing virtual machine operating systems.

Key Benefits:
- Multi-language support (Node.js, Python, Java, .NET, PHP).
- Automated OS security patching and infrastructure maintenance.
- Built-in Continuous Deployment (CI/CD) integrations with GitHub, Azure DevOps, and Bitbucket.
- Custom domain mapping and automatic free SSL/TLS certificates.

3. PREREQUISITES:
- An active Microsoft Azure Account (e.g., Azure for Students or Free Trial).
- Web browser (Chrome, Edge, or Firefox).

4. DETAILED STEP-BY-STEP PROCEDURE (AZURE PORTAL GUI):

Step 1: Login to Azure Portal
  1. Open your web browser and navigate to: https://portal.azure.com/
  2. Enter your registered Microsoft student/organization email and password.
  3. Complete Multi-Factor Authentication (MFA) to access the Azure Home Dashboard.

Step 2: Navigate to App Services
  1. In the top global search bar, type "App Services".
  2. Select "App Services" from the services dropdown list.
  3. Click "+ Create" (or "+ Add") and select "Web App".

Step 3: Configure Web App Basics
  Fill in the required fields under the "Basics" tab:
  - Project Details:
    * Subscription: Choose your active subscription (e.g., "Azure for Students").
    * Resource Group: Click "Create new" -> Name it `rg-mca-lab`.
  - Instance Details:
    * Name: Enter a globally unique name (e.g., `mca-skill-portfolio-2026`).
      (The public URL becomes: `https://<name>.azurewebsites.net`).
    * Publish: Select "Code".
    * Runtime stack: Select "Node 20 LTS" (or "Python 3.10").
    * Operating System: Select "Linux".
    * Region: Select nearest geographic location (e.g., "Central India" or "East US").
  - Pricing Plan:
    * Linux Plan: Keep default or click "Create new".
    * Pricing Plan: Click "Explore pricing plans" and select "Free F1" (1 GB RAM, 60 minutes/day compute) for zero-cost student lab practice.

Step 4: Review and Create
  1. Click the "Review + create" button at the bottom of the page.
  2. Review the summary of configurations.
  3. Click "Create".
  4. Wait for Azure Resource Manager (ARM) to complete deployment (takes ~1 to 2 minutes).

Step 5: Access and Verify Web App
  1. Once deployment succeeds, click "Go to resource".
  2. In the "Overview" page, locate the "Default domain" URL.
  3. Click the link (e.g., `https://mca-skill-portfolio-2026.azurewebsites.net`).
  4. The Azure default placeholder page (or deployed HTML page) will load in your browser.

Step 6: Deploy Custom Code (Optional via Deployment Center)
  - Go to "Deployment Center" in the left sidebar.
  - Choose "GitHub" as the source -> select repository and branch -> click Save.
  - Azure automatically generates a GitHub Actions workflow that builds and deploys your code on every Git push.

5. CONCLUSION:
The web app was successfully created on Azure App Service. This PaaS solution simplifies deployment, providing immediate cloud availability with built-in monitoring and zero server management overhead.
